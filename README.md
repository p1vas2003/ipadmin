IPADMIN — это автономная консольная утилита для инвентаризации и быстрого аудита локальной вычислительной сети

🚀 Быстрая установка (в одну команду)

Любой пользователь Linux может установить и сразу запустить сканер без установки Python и зависимостей:
`sudo curl -sSL https://github.com/p1vas2003/ipadmin/releases/latest/download/ipadmin -o /usr/local/bin/ipadmin && sudo chmod +x /usr/local/bin/ipadmin`

Чтобы запустить сканер, нужно в терминале написать одну команду:

`ipadmin`

Но лучше использовать права рута:

`sudo ipadmin`

# Общее описание программы


Что делает:

Автоматически определяет текущую активную подсеть (диапазон IP).

Опрашивает адреса диапазона и выявляет только «живые» хосты.

Идентифицирует устройства по сетевым именам (NetBIOS, FQDN/DNS).

Находит открытые порты управления (HTTP/HTTPS, админки роутеров, сетевых принтеров).

Выводит данные в виде аккуратных форматированных таблиц с прогресс-баром сканирования.

# Принцип работы со стороны системного администратора
Для инженера и сетевого администратора утилита выполняет последовательный пайплайн L3/L4/L7 разведки:

Host Discovery (Обнаружение доступности):

Для каждого IP в подсети запускается проверка доступности. В зависимости от прав (root или обычный пользователь) утилита отправляет ICMP Echo Request (ping) либо пытается установить быстрое TCP-соединение (TCP SYN/Connect) на популярные порты.

DNS Resolution (Обратный резолвинг DNS):

Для ответивших хостов выполняется PTR-запрос (reverse DNS lookup) для получения доменного имени узла в локальной зоне.

NetBIOS Name Service (Порт 137 UDP):

Отправка прямого UDP-запроса Node Status на порт 137. Если в сети есть Windows-машины, файловые хранилища Samba/NAS или сетевые МФУ, они возвращают имя рабочей группы/домена и NetBIOS-имя рабочей станции.

Port Probing & Service Detection (Веб-интерфейсы):

Сканирование типовых портов управления (80, 443, 8080, 8443). При обнаружении открытого сокета утилита формирует прямую гиперссылку (например, [http://192.168.1.1:80](http://192.168.1.1:80)), что позволяет сразу открыть админку оборудования в браузере.

Классификация и сегментация:

Устройства группируются по типам (шлюзы, сетевое оборудование, рабочие станции, принтеры) на основе ответов портов и сетевых имен. Результаты сортируются по числовому значению октетов IP-адресов.

# Архитектура и реализация со стороны разработчика
Программа построена по модульному принципу с упором на многозадачность I/O-bound операций:

Ключевые библиотеки и модули
concurrent.futures.ThreadPoolExecutor: Ядро многопоточности. Так как проверка сети упирается во время ожидания ответов сокетов (I/O bound), использование пула потоков ускоряет обход подсети /24 (254 адреса) с минут до нескольких секунд.

threading.Lock: Синхронизация потоков. Защищает разделяемые ресурсы (общий счетчик найденных хостов, отрисовку терминала и накопление словаря результатов) от состояния гонки (race condition).

socket: Низкоуровневая работа с сетью:

socket.gethostbyaddr() — асинхронный резолвинг PTR-записей.

socket.socket(AF_INET, SOCK_DGRAM) — отправка/прием байтовых пакетов NetBIOS NS Query (RFC 1002).

socket.create_connection() с жестко заданным timeout (обычно 0.3–0.8 сек) для быстрой отсечки закрытых портов.

ipaddress: Валидация подсетей, вычисление масок, широковещательных адресов и безопасная итерация по диапазонам IPv4Network.

locale / os / sys: Считывание переменных окружения (LANG, LC_ALL) для автоматической локализации вывода без сторонних громоздких пакетов gettext.

Форматирование вывода: ANSI-эскейп-последовательности (цвета, очистка строк, возврат каретки \r для динамического обновления прогресс-бара без мерцания).
